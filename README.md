# Ma Flo Kids - WordPress Conversion Project

## Project Overview
Converting the existing static HTML website to a modern WordPress website with a completely new layout and design.

## Project Structure

### 📁 Folders
- **`/docs`** - All project documentation
  - **`/specifications`** - Detailed website specifications
  - **`/analysis`** - Analysis of current site and requirements
  - **`/planning`** - Project timeline and development plan
- **`/original-site`** - Backup of original static website
- **`/website`** - Current live website (served at http://maflokids.local/)
- **`/wordpress-dev`** - WordPress development files
- **`/assets`** - Project assets (images, mockups, etc.)

### 🗂️ Key Files
- `mariadb-pw.txt` - Database password settings
- `maflokids.code-workspace` - VS Code workspace configuration

## Development Environment
- **Local URL**: http://maflokids.local/
- **Database**: MariaDB (credentials in mariadb-pw.txt)
- **Version Control**: Git (connected to GitHub)

## Project Phases
1. **Phase 1**: Analysis & Specification *(Current)*
2. **Phase 2**: Design & Mockups
3. **Phase 3**: WordPress Development
4. **Phase 4**: Content Migration
5. **Phase 5**: Testing & Launch

## Getting Started
Start with the specification phase by completing the documents in `/docs/specifications/`.
